## CRITICAL FINDING: Rules Are Underspecified [WARNING]

### The Issue
Tested with NaCl:
- **MatAgent verdict:** "Feasible battery material (score 1.0)"
- **Reality (Gemini):** "NaCl is insulator, not viable active electrode"
- **Root cause:** Current 25 rules only check:
  - [YES] Charge neutrality
  - [YES] Oxidation states
  - [YES] Stoichiometry
  - [NO] **Missing:** Ionic conductivity, electrochemical activity, band gaps, cycle life

### What Rules Check Now
- Chemical stability (charge balance, oxidation states)
- Basic thermodynamic viability
- **NOT:** Real-world battery performance (conductivity, cycling, voltage stability)

### Impact for Demo
- [YES] System architecture proven
- [WARNING] Rules need electrochemistry depth for credibility
- [NO] Cannot demo with arbitrary materials (NaCl fails real-world test)

- SSE events received correctly
- UI batches render instead of showing step-by-step

### Issue 2: Rules Too Simplistic (Addressed in Next Phase)

- Missing: Electrochemistry (conductivity, band gaps, cycle life)

- Non-blocking: Takes 10 seconds to set + restart
- Fix: Consider hardcoding in .env.local (post-demo)
