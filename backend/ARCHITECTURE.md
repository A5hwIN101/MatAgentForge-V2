### Chunk 3, Bucket 4: LangGraph + Groq Integration ✅ JUST COMPLETED

- LangGraph `StateGraph` with 6 nodes:
  1. `load_domain_rules_node` -> loads `rules/extracted_rules.json` (25 pre-trained rules)
  2. `candidate_analysis_node` -> parses formula via `pymatgen`
  3. `rule_verification_node` -> Groq checks each rule for violations
  4. `contradiction_detection_node` -> Groq finds rule conflicts
  5. `critique_generation_node` -> Groq generates verdict + flags + explanation (streaming)
  6. `finalize_critique_node` -> assembles final `CritiqueCard` payload
- Groq integration:
  - Model: `llama-3.2-90b-vision-preview` (latest, not deprecated)
  - Streaming `text.delta` events (word-by-word)
  - Error handling: retry once, emit `screen.failed` on failure
- SSE events wired: `screen.started`, `step.started`, `step.updated`, `text.delta`, `critique.ready`, `screen.completed`
- Environment: `GROQ_API_KEY` set via PowerShell before backend start
- Files: `workflow.py`, `state.py`, `screen.py` (updated), `requirements.txt` (updated)
- Test result: Real critique generated for `LiCoO2`, `verdict=feasible`, `score=1.0`, explanation generated by Groq
